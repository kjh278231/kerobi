# 스프린트 시작 시 작업자 선택

마스터 에이전트로 새 스프린트를 시작하라는 요청(예: "다음 스프린트 진행")을 받으면 작업자를 띄우기 전에 사용자에게 한 번 묻는다. 요청에서 이미 작업자를 지정했거나 같은 스프린트를 재개하는 경우에는 해당 선택을 사용한다.

> 이번 스프린트는 어떤 작업자로 진행할까요?
>
> 1. Claude Code (기존 방식)
> 2. pi agents (OpenGateway · GLM 5.3 Flash UltraFast)

대화형 선택 도구가 있으면 두 옵션을 표시한다. 없으면 위 문구로 묻는다. 답을 받은 뒤 선택한 작업자를 실행한다.

- Claude Code를 선택하면 [기존 위임 절차](../../docs/handoff/README.md#5-다른-에이전트에게-위임과-독립-검토)를 따른다.
- pi agents를 선택하면 [pi 작업자 설계](../../docs/16_pi_worker_design.md)의 출처 정책과 실행 방법을 확인한다. 저장소 자료 전송 범위가 승인된 작업을 해당 worktree에서 `tools/pi_worker.sh`로 실행한다. main worktree에 `.pi-run/run-worker`를 설정해 둔 경우에는 작업 worktree에서 그 실행 파일을 호출한다. 연결 설정이나 전송 승인이 없으면 이유를 알리고 작업자 선택을 다시 받는다.

마스터는 선택한 작업자와 관계없이 점유, 검증 계약, 독립 검토, 병합을 담당한다. 선택 질문은 마스터만 한다.
