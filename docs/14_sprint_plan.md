# 14. 1주 스프린트 작업 목록

기준일은 2026-11-10이다. [상위 작업 목록](13_work_units.md)의 번호를 유지하고, 실제 스프린트에는 아래 하위 번호를 사용한다. 스프린트는 1주다. 한 작업은 한 담당자가 조사·설계·구현·검증·기록을 마칠 수 있는 범위로 제한한다. 여러 작업을 한 스프린트에 넣는 것은 가능하지만, 상위 작업 전체를 넣지는 않는다.

## 1. 크기와 착수 조건

모든 항목의 검증 계약과 완료 판정은 [스프린트 동작 동등성 검증 기준](15_sprint_verification.md)을 따른다. 아래 종료 확인은 그 계약을 작성하기 위한 범위 요약이다. 착수 전에 [계약 양식](templates/sprint_acceptance.md)에 입력 상태·원본 구간·비교 필드·사례·오라클·재실행 명령을 구체화한다. 오라클을 확보하지 못한 구현은 원본 일치 완료로 판정하지 않는다.

계획 예산은 작업당 집중 작업 3일 이내와 검증·수정 여유 2일이다. 이는 실측 소요 시간이나 완료 보장이 아니다. 현재는 원본 조사량에 대한 작업별 실측이 부족하므로 아래 항목은 분할안이다. 착수 전에 원본 함수·모델·설정·완료 기준을 특정하고 3일 예산에 들어오는지 판단한다. 들어오지 않으면 기존 번호 뒤에 `-1`, `-2`를 붙여 더 나눈다.

종류는 조사, 구현, 검증이며 필요한 경우 오라클 구축을 별도 작업으로 둔다. 조사 완료는 정한 질문에 근거로 답한 상태다. 구현 완료는 계약 범위의 원본 구간 비교와 관련 회귀를 통과한 상태다. 검증 작업은 고정한 입력·설정의 결과와 불일치 판정을 남긴다. 실패 보고서의 완성과 기능 동등성 통과, 전체 관문 합격은 각각 구분한다.

원본이 미해독인 구현 항목은 **설계 대기**다. 먼저 연결된 조사 작업을 끝내야 한다. 조사에서 발견한 모든 함수를 같은 스프린트에 구현하는 방식으로 범위를 늘리지 않는다. 미해독 함수가 남으면 범위를 명시한 후속 번호를 만든다. 미확인 상태를 원본 일치로 판정하지 않는다.

기능 가족 여러 개를 다루는 조사도 산출물은 호출 경계와 후속 분할표까지다. 전체 알고리즘 해독은 포함하지 않는다. 착수한 뒤 2일째에 남은 조사·검증이 예산을 넘는다고 판단되면 함수 또는 사례별로 즉시 나눈다. 아래 표의 선행 조건이 남은 항목은 예약 후보이며 현재 착수 가능하다는 뜻이 아니다.

공통 완료 조건은 상세 기록에 원본 파일과 함수, 확인한 분기, 입력·파라미터, 재실행 명령, 결과, 남은 한계와 커밋 상태를 남기는 것이다. Rust 구현은 해당 크레이트 검사부터 시작하고 영향 범위에 맞는 workspace·Python 검사를 수행한다. Gurobi 오라클은 한 프로세스씩 실행한다.

## 5. 다음 스프린트 제안

M2-03a와 M2-03b-1 조사를 완료했다. 선형 루트 무계 확정과 자식 LP 상태 5→12 재분류, 즉시 재풀이를 구분했다. 노드 상태 3은 대체 분기의 입력이며 같은 노드 재등록 대상은 아니다. 원본 합성 구간 156회가 일치했지만 호출자와 실제 자식 연결은 미검증이다. M2-03c-1은 부분 완료로 병합했다. 자연 상태 12 재풀이와 상태 3 호출자 `682037`의 원본 동작을 3회 검증했다. M2-03c-2는 완료했다. 재풀이 입력은 노드 저장 basis이고, 재풀이 뒤 원본 export는 LP 상태에 따라 없거나(nidda) `5d4427`이 만든다(gmu). M2-03d-1 조사로 원본 사례는 Rust 자연 실행으로 도달할 수 없음을 확인하고, 원본 LP 결과를 주입한 재풀이 제어 재생(L1)을 경계로 정했다. M2-03d-2는 사용자 승인 뒤 L1 구현을 완료했다(실제 경로 미연결). M2-03d-3 노드 LP 오라클을 완료했다. 두 사례는 RINS 고정 연속부 LP와 sub-MIP 루트이고, 노드 LP 기준 파일을 만들었다. 실제 경로 연결과 LP 포함 동등성은 M2-10b·M1 요청·03d-3 뒤 M2-03d-4에서 한다. 상태 10 생성과 `682037` 진입 조건의 의미는 M2-03c 범위에 미검증으로 남는다. 추가 제약 ray의 M2-03b는 별도로 남는다.

설계 대기인 큰 영역의 총 소요 스프린트 수는 아직 산정하지 않았다. 상위 번호 수나 이 표의 행 수를 남은 스프린트 수로 환산할 수 없다. 설계 조사에서 새로 생기는 구현 작업과 재측정에서 발견하는 불일치가 남은 양에 포함된다.
