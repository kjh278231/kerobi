## 2. `45feaa` two-row (21,340 B, `0050da00`)

1. 행 목록은 `53b99a`(5,989 B): `53c422`의 행 판(표시된 행 + `53af0f` 열들의 행, 캐시 tracker+0x130). `adjacent_any(cols, hop2)`의 두 번째 단계가 `adjacent_list(!cols)`를 쓰도록 일반화했다.
2. lim(열 길이 상한): mode 1이면 m < 257 → 32, 아니면 `(int)(√m + √m)`. 그 밖 `(int)(√nnz + √nnz) + 32`.
3. 목록 행 중 row_cnt > 1인 행의 CSR 사본(행 리스트 순서, `W += (방문·5)·μ`, 끝에 `(m·3)·μ`) → `7722f`로 열 CSR(작업량에 μ 없음, `helpers::transpose_csr`로 `4030c9`와 공유) → `(m·3)·μ` → 목록 행마다 `(len·2)·μ`, 끝에 `(목록·4)·μ`.
4. 행 i마다(2 ≤ row_cnt ≤ 1e6): 1e7 작업량마다 예산 검사, `adf2be(T7)`면 끝. 사본에서 col_cnt ≤ 0 열을 빼고(`(len·3)·μ`), |a| < 1e-6이 있으면 건너뜀. 열마다 dense[c] = a_ic, col_cnt ≤ lim인 열의 다른 행 r(1 < row_cnt[r] ≤ 1e6)에 겹침 수와 점수 Σ|a_rc|·(ub−lb)(무한 폭은 (폭/INF)·1e100) 누적. 거르기: 겹침 ≥ 2, 2·겹침 ≥ min(row_cnt), 점수 < 0.8·(act_max − act_min)이면 버림(겹침 < row_cnt[r] − 1이고 r이 늘 만족되지 않을 때만). Σrow_cnt[r] > 2·Σcol_cnt[i 열]이면 겹친 항을 행별 버킷(채우는 순서의 역순)으로, 아니면 r 행 전체를 훑는다(겹치지 않은 항 목록을 그때 같이 만든다. 버킷 모드는 처음 쓸 때 만들고 `(len·7)·μ`, 이 목록은 같은 r의 두 방향에서 재사용).
5. 방향 0: i의 min 무한 항이 모두 겹친 쪽에 있으면 b = act_min[i] − minI로 `45d7ec`(겹친 열, c = a_r, a = −a_i). 방향 1: i가 `=`이고 r이 지워지거나 계수가 바뀌지 않았으면 a의 부호를 뒤집어(`W += 개수·μ`) b = maxI − act_max[i]. 결과 (hi, lo)로: `=` r이 불가능(3, +0x478 = i, +0x47c = r), `<` r의 불가능·중복(행 제거 −2, 열 표시·col_cnt−1, 레코드 없음, NumericFocus ≥ 1이면 큰 비율 검사), 겹치지 않은 열의 bound 후보(min 쪽 전부/무한 하나, `=`면 max 쪽도; 정수는 FeasibilityTol로 floor/ceil), `<` r에서 lb = 0 정수 열의 계수 강화(이진 a > s+tol이면 a → s, rhs −= a − s; a < −(tol+s)면 a → −s; 0이 되면 1e-200 표시 → 노드 삭제).
6. 계수가 바뀐 r의 사본 행은 **바뀐 항만 남는다**(newcoef가 0인 항은 첫 비교 |v − 0| < 1e-13도, 둘째 분기 nc ≠ 0도 아니라 빠진다). 원본 그대로 옮겼다.
7. 행 i 끝: `(kept·9)·μ`, dense 지우기 `(len·2)·μ`, bound 후보 적용(lb 먼저, ub는 max(lb, nu); 바뀐 열의 행을 모아 `370047`), ub − 1e-10 < lb면 `3df916`. +0x404 += 지운 행 수(함수 끝).

## 2a. `45d7ec` 한 제약 LP (4,820 B, angr)

max/min c·x s.t. a·x ≥ b, 열 bound 안. 두 문제를 한 번에 훑는다(min 문제는 버퍼 앞에서부터, max 문제는 (−c)로 min 형태가 되어 버퍼 끝에서부터 쌓는다). 항목마다 시작점(양쪽에 좋은 bound), 무게 (u−l)·|a|(무한이면 1e100), 비율 c/a. 시작점이 무한이면 rmax(되돌릴 수 있는 최대 비율) 또는 무한 플래그. 그다음: 무한이면 ∓1e100; rmax > 0이면 비율 ≤ rmax인 항목을 다 넣고(무한 무게면 비유계) `(2·k)·μ`; 남은 요구량 b < 1e-10이면 값 결정, 아니면 quickselect(Hoare, 가운데 피벗)로 누적 무게가 b에 닿는 항목을 찾고 `(2n)·μ`, 마지막에 앞부분 합 `μ·(2·lo)`. 합은 SSE: 8개 이상이면 16 B 정렬까지 하나 벗기고 2-lane 누적기 4개, ((l+m)+(n+o)) 뒤 lane 합. 버퍼는 glibc malloc이라 16 B 정렬로 보고 벗기기 = 시작 인덱스 홀짝이다. 끝 단계 내적은 누적기 하나에 곱을 사슬로 더한다. 결과 hi = −(max 쪽 min 형태 값).

확인: 45feaa 78/78(lb·ub·행 제거·계수 강화 경로 모두 포함). 처음 어긋난 것은 겹치지 않은 항 목록을 한 r에서 두 번 만든 것(7·항목 작업량)뿐이었다.

## 3. `5466a7` VUB 병합 (11,233 B, `0059bd80`)

- 목록 `53af0f`(열). 열 j가 col_cnt > 1, 'B', lb ≤ 0.5 ≤ ub일 때만: `adf2be(T13)`면 끝, 작업량이 지난 검사보다 1e7 넘게 늘었으면 예산 검사(기준값은 0에서 시작).
- 1단계: j 열의 살아 있는 노드 중 row_cnt == 2인 `<` 행 r에서 다른 열 k를 찾고(행 머리부터 죽은 노드·j를 건너뛴 수 s, `W += (s+s)·μ`), d = ub_k − lb_k > 1e-13, ||a_j/a_k| − d| ≤ 1e-13이면 종류: a_k < 0이면 (a_j > 0, rhs/a_k ≈ lb_k) 1, (a_j < 0, ≈ ub_k) 2; a_k > 0이면 (a_j > 0, ≈ ub_k) 3, (a_j < 0, ≈ lb_k) 4. k에 아직 종류가 없으면 표시(st+0x3a8)하고 목록(2·4 → 0, 1·3 → 1)에 넣는다(a_k < 0이면 −1−k). 이미 있으면 충돌·중복: j나 k 고정(`3de18e`), 행 삭제(`397538`), 대입 쌍 기억(`564ce0`, AggMultLimit 검사). 끝에 `(방문·9)·μ`, 목록마다 표시 지우기 `(len+len)·μ`.
- 2단계(목록 길이 > 1인 쪽, j가 아직 [0,1]): j의 row_cnt > 2 행을 1로 표시(`(방문·5)·μ`), 목록 열 k(0 ≤ col_cnt ≤ 10000)의 부호가 맞는 노드의 행 수를 센다(`(μ·5)·방문`), `(len·3)·μ`. 1 < 표시 == row_cnt, `<`, act_min ≤ −0.001인 행이 남으면 합친다.
- shortcut: 1단계 충돌 처리와 2단계 합치기는 옮기지 않았다(38개 모델에서 한 번도 안 일어난다: 78호출 모두 작업량만 바뀜). 덤프 78/78.
