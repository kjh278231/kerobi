# M1-02k BTRAN Uᵀ 희소 판정 검증 계약과 결과

## 1. 범위와 주장

- 종류: 구현. 기준 main `7662800`, 미커밋 선행 변경 없음(main의 미추적 `.env`는 사용·변경하지 않음).
- 동작: BTRAN `221173` C:88–90의 Uᵀ 경로 판정 `(int)(LU+0x108 + LU+0x110)·nnz ≤ m`(입력 nnz ≥ 0)을 Rust `Lu`의 두 경로에 옮긴다.
  - 대각 U 경로(`btran_dense`): 지금은 `3·nnz ≤ m` 고정.
  - 갱신·일반 U 경로(`btran_updated`): 지금은 C:89 판정이 없고 Uᵀ 출력 수로 eta·Lᵀ 경로를 정한다. 조밀 Uᵀ면 원본은 출력 nnz −1이므로 eta와 Lᵀ도 조밀이다(C:186–260, C:1237–1766). 조밀 Uᵀ는 `|x| ≤ ZERO` 또는 `|x/d| ≤ ZERO`면 0으로 둔다(C:196).
  - `9e376`(dual e_r, param_4 ≠ NULL)은 U 행 r이 비어 있지 않으면 희소 Uᵀ로 강제하고, 비어 있으면 일반 판정으로 간다(C:1196–1206).
- 착수 전 탐색(판정 근거 아님, 저장소 밖 scratchpad): Netlib 64 Method=1 원본 BTRAN 66,084호출의 입력 nnz는 −1(c_B) 또는 1(e_p·e_r)뿐이었다. `(int)D`는 3–21이고, `21a941` 호출 여부는 일반 판정 예측과 모두 같았다. **기존 `3·nnz`와 새 판정이 갈리는 자연 호출은 0회**다. 그래서 사용자 확인을 받아 합성 경계(실제 LU에 원본 `9e288`을 직접 호출, 선택한 RHS)를 포함한다.
- 제외: LU 풀이 work(M1-02t), `21a941`의 LU+0x108 > 5 경로 출력 순서의 별도 원본화(관측만 함), Lᵀ 선형 경로(L956), quad·Threads > 1·primal·MIP 호출자.

## 2. 원본과 상태 경계

- Gurobi 13.0.3, SHA-256 `8e87fca221fdffc922331c8619426031b3e72dfd419446422f88af0cb0e98f9c`.
- 원본: `../re/decomp/c/0012de60_PRIVATE0000000000221173.c` C:76–90(판정), C:91–260(조밀 Uᵀ), C:1196–1240(`9e376` 강제), `00130b70_…21a941.c` C:69(LU′+0xe8 = LU+0x108만 읽음). 래퍼 `9e288` 0x12de10·`9e376` 0x131710 진입이 `push`이고 LU+0x200을 0으로 둔다(asm 0x12de1c·0x131720).
- LU+0x110은 C:85에서 읽고 C:89에서만 쓴다(그 뒤 dVar55는 재할당). 따라서 합성 호출에서 LU+0x110만 잠시 바꾸면 판정만 강제할 수 있다. `21a941`은 LU+0x110을 읽지 않는다.
- 자연 경계: `221173` 진입·반환(입력 nnz, LU+0x108·0x110 비트, LU+0x180, LU+0x104, `9e376`의 U 행 r 길이, `21a941` 호출 여부, 출력 nnz).
- 합성 경계: 지정한 dual 피벗 k에서 `9e376`(28c93의 e_r, 반환 0xc51dd) 반환 직후. 그 LU로 `9e288(LU, in, out, NULL)`을 RHS마다 세 번 부른다: 자연 D, 희소 강제(LU+0x110 := −LU+0x108), 조밀 강제(LU+0x110 := m + 2). 각 호출 뒤 출력과 LU+0x200을 기록하고, 끝에 LU+0x110·0x200을 원래 비트로 되돌린다. 자연 결과가 강제 결과 중 정확히 하나와 같으면(출력 비트·순서 + LU+0x200) 그것이 원본 판정이다.
- 설정: Method=1, Presolve=0, Threads=1. Rust는 같은 모델에서 같은 e_r 호출 번호 k의 같은 지점(`simplex.rs` e_r BTRAN 직후)에서 같은 RHS로 계산한다.

## 4. 사례와 기준 자료

| 사례 | 실제 / 합성 | 노리는 분기 |
|---|---|---|
| 자연 BTRAN 전 호출 | 실제 | c_B(−1), e_p·e_r(1), `9e376` 강제/일반 |
| kb2·degen2 FT 갱신 뒤 피벗 | 합성 RHS, 실제 LU | 갱신 경로, LU+0x104 큼(Lᵀ 조밀) → 판정은 work로 식별 |
| LU+0x104 = 2인 모델(sc50b·scsd1·stair·forplan·fit1p) | 합성 RHS, 실제 LU | 희소 Uᵀ면 희소 출력. D > 5(`21a941` 다른 경로)는 forplan·fit1p |
| 분해 직후 대각 U | 합성 RHS | Rust 대각 경로, D = 3 |

RHS는 피벗마다 nnz ∈ {1, ⌊m/D⌋, ⌊m/D⌋+1, ⌊m/3⌋, ⌊m/3⌋+1, ⌊m/2⌋}(중복 제거)이고 위치는 고르게 퍼진 오름차순, 대역 m/D < nnz ≤ m/3 사례 하나는 역순도 둔다. 값은 정확한 2진 값. 판정이 갈리는 대역 사례(기존 `3·nnz`와 새 판정이 다른 입력)가 모델마다 적어도 하나 있어야 한다.

- 적용 안 함: D가 2인 분해(탐색에서 관측 없음), m < D인 모델(Netlib에 없음, `9e376` 강제가 결과를 바꾸는 유일한 경우).
- 오류 검출: 원본 해시·빈 사건·판정 미식별·합성 출력·D 비트·회차 차이 변조, 그리고 기존 `3·nnz` 판정(기준 빌드)이 대역 사례에서 거부되는지.
