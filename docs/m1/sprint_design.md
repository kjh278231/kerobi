# M1 스프린트 설계 보완

이 문서는 [1주 작업 목록](../14_sprint_plan.md)의 M1 작업을 위한 설계 경계다. 이미 확인된 알고리즘은 기존 명세를 따른다. 새 수치 규칙은 원본 확인 뒤 해당 작업 기록에 추가한다.

착수와 완료 판정은 [동작 동등성 검증 기준](../15_sprint_verification.md)을 따른다. 이 문서의 비교 경계를 작업별 [검증 계약](../templates/sprint_acceptance.md)의 필드·사례·명령으로 구체화한다.

## 1. 상태와 비교 경계

| 경계 | 현재 위치 | 설계에서 고정할 내용 | 비교 지점 |
|---|---|---|---|
| 입력→스케일링 | `crates/lp/src/scaling.rs` | 입력 bound·행 방향·목적 방향과 저장 스케일 | A·c·lb·ub·rhs·스케일 인수 |
| 시작 상태→첫 반복 | `start.rs`, `spx.rs` | basis·열 상태·RNG의 초기 소유권 | 반복 0 basis·xB·reduced cost·가중치 |
| basis 갱신→선형 해법 | `lu.rs` | 갱신 파일과 factor의 수명, 재분해 조건 | 같은 입력 벡터의 FTRAN·BTRAN 출력 |
| 반복 | `simplex.rs`, `pricing.rs`, `bfrt.rs` | 후보 순서·flip 순서·섭동 해제·상태 확정 | 선택 직전과 갱신 직후 상태 |
| 풀이→복원→설치 | `crates/driver`, `presolve/postsolve.rs` | 축약·원래 좌표, 목적 상수·sense 적용 횟수 | 복원 전후 목적과 원래 제약 위반 |

각 조사 작업은 원본 함수와 어셈블리에서 필요한 구간을 특정한다. 함수 호출 인자나 SIMD 순서가 불명확하면 구현 항목은 설계 대기로 남긴다. 인터페이스 재작성은 기본 범위에 포함하지 않는다. 기존 상태를 오라클에 대응시킬 수 없는 경우에만 필요한 필드를 먼저 정한다.

## 2. 최초 분기 하나를 닫는 설계

M1-02a·M1-03a의 입력은 모델 하나, Method, Presolve, Threads, Seed와 같은 시작 상태다. 산출물은 최초로 달라지는 반복, 필드, 그 필드를 마지막으로 쓴 원본 함수, 동일 입력의 Rust 연산이다. 끝까지 다른 반복 수만 기록해서는 조사 완료가 아니다.

구현 작업은 그 원인 하나만 바꾼다. 후보 열·행의 선택, 동률 순서, 허용오차 또는 연산 순서 중 확인된 범위로 한정한다. 회귀는 해당 모델 궤적을 비교한 뒤 Netlib 64로 넓힌다. 64개에서 새 차이가 생기면 입력 상태부터 기록하고 별도 원인으로 분리한다.

## 3. 드라이버 목적·웜스타트 계약

M1-06a는 축약 목적, postsolve 직후 목적, Python에 설치된 목적을 각각 비교한다. `objcon`과 최대화 부호가 적용되는 위치를 표로 작성한다. etamacro의 목적 차이를 발견한 경계가 구현 위치를 결정한다.

M1-06c는 같은 원본 basis와 원시·쌍대 해를 양쪽에 넣고 설치 직후의 열 상태, 기본 변수 값, reduced cost와 feasibility 판정을 비교한다. 추가 반복을 무조건 줄이는 방식으로 맞추지 않는다. 설치 규약이 일치한 뒤에도 반복이 다르면 M1-02 또는 M1-03의 새 하위 작업으로 넘긴다.

## 4. 검증 산출물

각 작업 기록은 모델·설정, 기준 덤프 경로, 재실행 명령과 첫 차이를 포함한다. M1-07은 구현 누락을 같은 스프린트에서 모두 고치는 작업이 아니다. P0~P3 측정표와 판정을 만든다. 불합격 이유에는 다음 작업 번호를 연결한다.

M1-02v는 반복 커널 19지점 work를 기존 캡처 재생으로 검증했다. bound flip FTRAN의 기존 수치 결과와 반환 표현 판별을 분리해 경로를 보존했다. 중복 L/R 계산의 통합은 M1-02t 커널 검증 범위에서 다룬다. 다음 순서는 M1-02k → 02t이며, 별도 fold는 02u다. [검증 계약](m1_02v_iteration_work.md).

M1-02k는 BTRAN Uᵀ 판정과 `21a941` 순서를 합성 RHS·자연 c_B 대조로 검증했다. 같은 피벗 재분해의 꼬리 U 원소 수 차이(LU+0x108)는 M1-02w로 분리했다. 다음 순서는 M1-02w → 02t → 02u다. [검증 계약](m1_02k_btran_ut.md).
