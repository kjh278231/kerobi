### 2.1 호출 지점 `5ce67b` C:1183–1250

LP 상태 3(infeasible), 루트 밖(`local_128 != piVar21+0x1e4`), `lp+100 == 3`, `M+0x346c ≠ 0`, `S+0xe0 ≠ 0`, `a7f0ad`·`a7f923` 0일 때 `L+0x70`·`L+0x78`(n+m 칸, 이미 있으면 재사용)을 할당하고 `L+0x3c = m`을 둔 뒤 부른다.

```text
rc = 95da98(xmm0 = 1e-10, S, M, ctx, M+0x32e8, &L+0x58, &L+0x54, &L+0x60, &L+0x5c, &L+0x68,
            L+0x70, L+0x78, 2, &fail, work)
rc == 0 && fail == 0 && env+0x2a40 ≠ 0 이면 5d80d8(ctx, …)
fail ≠ 0 || rc ≠ 0 이면 L+0x70·L+0x78 해제, L+0x58 = -1
```

Frida 인자: xmm0가 첫 인자라 `a[i]` = C `param_(i+2)`. `a[4]` = &L+0x58, `a[5]` = &L+0x54, `a[6]` = &L+0x60, `a[7]` = &L+0x5c, `a[8]` = &L+0x68, `a[9]` = ray, `a[10]` = bnd, `a[11]` = 2, `a[12]` = &fail, `a[13]` = work.

### 2.2 기호

`lp = S+0xe8`: m = `lp+8`, n = `lp+0xc`, rhs `lp+0x380`(m), lb `lp+0x390`, ub `lp+0x398`(n+m, 슬랙 bound 포함. 기저 변수 j가 슬랙이어도 `lb[j]`·`ub[j]`를 읽는다), 행 스케일 R `lp+0x3d8`(m, null 가능), 열 스케일 C `lp+0x3e0`(n, null 가능), flip 방식 `lp+0x3c`, flip 표시 `lp+0x408`(n 바이트). `spx = S+0xe0`: 행 r = `spx+0x2f8`, 기저 값 x_B `spx+0x1e8`, 상태 `spx+0x168`(n+m; 음수 = 비기저 −1/−4 하한, −2/−5 상한, −3/−6 자유·초기저), head = `12dcea(spx)`. tol = 1e-10(xmm0), δ = `S+0x100+0x2460`, ∞ = `S+0x100+0x2458`. 표 행 α = `12ea3f(S, r, vec, …)`의 희소(개수 ≥ 0) 또는 조밀(개수 < 0) 벡터, 첨자 k < n은 열, k ≥ n은 행 k−n의 슬랙.

### 2.3 규칙(C 해석, Q1·Q2의 예측)

```text
*L58 = -1; f = +1 (local_60)
for try in 0..2:
  st = S+100
  st ∈ {2,5}          → fail 1
  st == 6             → fail 3 (break)
  st == 3 and spx:
    q = spx+0xf4; q ≥ 0 and spx+0xb0[q] + δ ≤ spx+0xa8[q] → fail 3 (break)
    (spx+0x4a0 or spx+0x478) and r ≥ 0:
      α = 12ea3f(r)               (rc ≠ 0 → 반환 rc)
      j = head[r]; *L58 = j; x = x_B[r]
      x ≥ ub[j]+δ → s = -1;  x ≤ lb[j]-δ → s = +1;  그 밖 → fail 1
      j < n, lp+0x3c > 0, flip[j] → f = -1, s = -s
      *L54 = s
      bnd (C 있으면): j < n: x·C[j] (C[j] > 1e7 → fail 3), j ≥ n: x / R[j-n] (R < 1e-7 → fail 3)
                     k < n: 상태 −1/−4 → lb·C, −2/−5 → ub·C, 그 밖 0; 슬랙 0; bnd[j] = x(스케일);
                     flip[k]이면 bnd[k] 부호 반전
      ray: 전부 0, α의 각 k에 대해 d = |α_k| / min(1, C[k] 또는 R[k-n]) (ctx null이면 |α_k|)
           d ≠ 0 슬랙이고 7889ec(X, ctx, k-n) ≠ 0 → fail 4
           d > 1e7 → fail 3
           d > tol: 상태 < 0 → ray_k = f·α_k, 상태 −3/−6이면 fail 2
                    k == j → ray_k = 1, |α_k − f| > tol 이면 fail 2
                    그 밖(다른 기저) → fail 2
           그 밖 ray_k = 0
      ρ = Σ_{i<m} rhs_i·ray_{n+i} (/R_i), |ray_{n+i}| > 1000 → fail 6
      bnd 있으면 |(ρ − Σ_k bnd_k·ray_k)/100| > tol → fail 2   (값은 저장 안 됨)
      ν² = (lp+0x3c == 2 ? 1e-200 : 0) + Σ_{k<n} ray_k²;   ν² < 1e-4 → fail 5
      a = Σ_{k<n} ray_k·b_k,  s·ray_k ≤ 0: b = ub·C (ub ≥ ∞ → 1e100; flip 방식 1·flip이면 −lb·C)
                              s·ray_k > 0: b = lb·C (lb ≤ −∞ 또는 flip 방식 1·flip이면 −1e100)
      ν = sqrt(ν²); *L68 = s·(a − ρ)/ν; ray /= ν (n+m 칸); *L60 = ρ/ν
      *L5c = max_{t: |ray_{n+m0+t}| > 1e-10} cut[t]+0x38   (cut = (M+0x3240)+0x78, m0 = 원래 행 수, 시작 0)
      성공(fail 0)
    그 밖: cda5b(S, 1, …) 다시 풀기, try += 1
실패: *L58 = -1, *L54 = 0, *L60 = 0, *L5c = 0, *L68 = 0;  *fail = 코드
```

work(`a[13]`)는 각 고리 뒤 정해진 배수로 더한다(C의 `*param_15 += …`). `12ea3f` 반환 뒤부터 순서대로: bnd 채우기 n·4(열 스케일 있음) 또는 n·3, 슬랙 0 채우기 m, 희소 α면 +(n+m), ray 고리 처리한 칸 수·4(실패면 실패 칸 번호·4), ρ 고리 m·3(행 스케일 있음) 또는 m+m, 잔차 2(n+m), ν² 고리 n·4 또는 n·3, 정규화 n+m, cut 고리 2m(m ≤ m0이면 2m0). fail 6은 ρ 고리 몫을 더하기 전에 나간다.

### 2.4 쓰는 쪽과 감쇠 입력(C, 캡처로 확인)

- `5d80d8`(`0x4f6650`, 성공 직후 `env+0x2a40 ≠ 0`): ray·`L+0x54`·`L+0x60`을 **읽기만** 한다. ray의 |값| > 1e-10 칸(cut 행은 `788a84`로 거름)으로 bound를 조이는 함수다(`a7cec0`, `6fc004`의 `'<'`·`'>'`). ray를 바꾸지 않는다(C 전문, 캡처: 직후 비교 차이 0).
- `5fb8ec` C:2210–2228: `L+0x38 == 3`, `L+0x58 ≥ 0`, `L+0x68 ≥ 1e-4`, ray 있음이면 (`env+0x2a48 ≠ 0`일 때) **`6684cd`(`0x554ee0`, 986줄)가 ray를 제자리에서 고치고**(C:736–767, 981 memcpy) `L+0x60`·`+0x5c`·`+0x68`도 다시 쓴다(C:976–978). 이어서 `68c35b`(ρ, s, …, ray, …, `L+0x5c`+1)가 ray를 읽어 conflict 저장소에 넣는다(쓰지 않음).
- 그래서 감쇠 `6ee1d3`이 읽는 `L+0x70`은 `6684cd`가 바꾸지 않았으면 `95da98` 출력, 바꿨으면 `6684cd` 출력이다. 이 사실은 첫 시험 캡처에서 감쇠 때 벡터가 `95da98` 반환 때와 다른 사례(pk1 37회 중 13회)로 드러났고, 함수 경계 비교(`5ce67b` 반환 뒤·`6fdec9` 앞 → `6684cd`)로 찾았다. `6684cd`의 계산 해독은 범위 밖이다(M2-06f-5).
