# M2-06f-3 검증 계약과 결과: 노드 수명 모형 Rust 이식

작성 기준은 [스프린트 검증 기준](../15_sprint_verification.md)이다. 원본 규칙과 기준 자료는 [M2-06f-2](mip_node_life.md)다. M2 인수인계의 첫 다음 작업이고, 사용자의 "다음 스프린트 진행" 지시로 착수했다(2026-11-11).

## 1. 범위와 주장

- 작업 종류: 구현(L1 저장 기준 재생).
- 완료 후 주장할 것: 새 `crates/mip/src/node_life.rs`의 `NodeLife`(`create` = `5ff358`, `release` = `5f9d4e` → `5fa560` 연쇄, `ancestors` = `6ee1d3`이 걷는 조상)에 06f-2 6사례 run 1의 노드 생성(`nn`)·해제 요청(`rel`)·감쇠(`dec`) 사건만 넣으면 다음이 원본 캡처와 같다.
  - 해제 요청마다 이전 단계(`I+0x68`, I가 없으면 없음), 단계 6이면 이전 L 유무.
  - 이어지는 `5fa560` 호출 열(노드, 단계)과 호출마다 앞뒤 상태(N 해제, I·L 유무).
  - 감쇠마다 현재 노드의 I·L 유무, 조상 열(I 없는 조상에서 끝나면 그 조상 포함)과 끝 이유(`noI`·`nop`).
- 포함 분기: 단계 0·3·4 해제, 단계 6 L 생성(이미 있으면 유지), 자식 수 `N+0x22` 연쇄(부모 단계 0), 부모 `I+0x6c` 0 → 부모 I 해제(단계 1), `old < 5` 멈춤, `s > 4` 멈춤, 루트 예외(단계 1–5에서 아무것도 안 지움), 부모 없는 비루트 노드(`8e4682` 등, 06f-2 6사례 427개).
- 입력 전제: 입력은 캡처 사건의 `nn`(부모 일련번호, 루트 표시 = 출력 칸이 `M+0x790`), `rel`(노드, 단계), `dec`(노드)뿐이다. `rel.old`·`rel.L`·`fr`·`fr_`·`dec.noI`·`noL`·`as`·`end`는 기대값으로만 쓴다. 06f-2 판정기의 Python 모형(`replay`)은 입력·기대값에 쓰지 않는다. 루트 표시는 부모 유무에서 추론하지 않는다.
- 제외 범위와 후속:
  - `bnb.rs` 연결: 감쇠 범위가 원본과 같으려면 노드 처리·힙 이동 순서(06c·06d)가 같아야 하고, 감쇠 벡터(LP 환산비용·cutoff 상태, M1 경계)와 `95da98`(06f-4)도 필요하다. 06b처럼 이식만 한다.
  - `5f9d4e`의 트리 계정(T+0x10 노드 수, T+0x20 바이트): 수명과 무관해 넣지 않는다(코드 `shortcut:` 주석).
  - 노드 페이로드(bound 목록, basis, L 벡터, cut 정보): 호출자가 들고 `release`가 알려 주는 `5fa560` 호출로 지운다. N 재할당(`ac6569`)은 주소 문제라 Rust에 해당 없다.
  - 단계 −1·1·2·5 직접 호출, 부모 단계 < 3 멈춤(루트 재진입 가드), 지연 목록·node file·병렬: 06f-2 6사례에서 0회. 코드는 C대로 옮기되 미검증으로 둔다.
- 선행: main `7e47a1e`(M2-06f-2 병합 포함), 미커밋 선행 변경 없음.

## 2. 원본과 상태 경계

- Gurobi 13.0.3 `libgurobi130.so` SHA-256 `8e87fca221fdffc922331c8619426031b3e72dfd419446422f88af0cb0e98f9c`. 주소는 file offset.
- 이번에 다시 읽은 C(`re/decomp/c/`):

| 함수 | 위치 | 옮긴 규칙 |
|---|---|---|
| `5ff358` `0x5177f0` | C:40–90 | 새 I 단계 `I+0x68 = 5`. 부모가 있으면 부모 I를 읽고(부모 I 필요), basis 복사 성공 뒤 `parent+0x22 += 1`, `N+0x10 = parent`, 부모 `I+0x6c += 1`. N·I는 0으로 할당(자식 수·`+0x6c` 0) |
| `5f9d4e` `0x516bc0` | C 전문(161줄) | −1 → 0. 6: L(`I+0x08`)이 있으면 그대로 반환, 없으면 생성(`I+0x68`은 안 씀). 그 밖: 연쇄 루프(아래) |
| `5fa560` `0x516f10` | C 전문 | I 없음: 0이면 N 해제. 루트(`N == M+0x790`): s > 0이면 반환, 0이면 L·cut·I·N 모두 해제와 `M+0x790 = 0`. 그 밖: s > 5 반환, L·cut 해제, s > 2 반환, I 해제(`N+0x18 = 0`), s ≠ 0 반환, N 해제 |
| `6ee1d3` `0x5b73d0` | C:36–38 | 조상 걷기 `A = N+0x10`부터 `A ≠ 0 && 0.001 < w && A+0x18 ≠ 0`인 동안. w 조건은 `Pseudocost::decay` 몫이고 `ancestors`는 I 있는 조상만 낸다. 06f-2 훅의 40개 한도는 원본이 아니다 |

```text
5f9d4e 연쇄 (X = N, s)
  old = X.I ? X.I+0x68 : 1;  X.I 있으면 X.I+0x68 = s
  5fa560(X, s)
  P = X+0x10;  없으면 끝
  s == 0 이면 P+0x22 -= 1
  P+0x22 == 0 이면 X = P, s = 0, 처음으로
  P.I 없음 / s > 4 / old < 5 이면 끝
  P.I+0x6c -= 1;  0이 아니면 끝;  P.I+0x68 < 3 이면 끝
  X = P, s = 1, 처음으로
```

- 시작·끝: 사건 하나는 원본 함수 호출 하나(`5ff358` 반환, `5f9d4e` 진입과 이어지는 `5fa560` 진입·반환, `5fe9cd` 감쇠 입구 `dec`).
- 상태: 노드별 부모, 자식 수(`N+0x22`), 단계 5 자식 수(`I+0x6c`), 단계(`I+0x68`), I·L 유무, 루트 표시, N 생존. 노드 식별은 생성 순서 일련번호(06f-2 `nn.s`; 6사례 모두 0부터 1씩 증가 확인)이고 Rust `create`의 반환값과 같아야 한다.

## 3. 비교 계약

`tools/mip_node_life_rust.py`가 판정한다. 하나라도 실패하면 종료 코드 1이고 첫 차이(사례·사건 번호·입력 줄·기대값·Rust 값·검사)를 출력한다.

| 검사 | 규칙 |
|---|---|
| M 입력 | 6사례 run 1의 SHA-256이 `bench/oracle/m2_06f2/manifest.json`과 같다(06f-2 L1이 run 2·3을 같게 만든다) |
| X 재생 입력 | `nn`·`rel`·`dec` 사건에서 입력 줄만 만든다. 입력 끝 `end` 줄이 없으면 Rust가 실패한다. `rel` 단계는 0·3·4·6만 있어야 한다(그 밖은 실패) |
| C 생성 | `nn`마다 Rust id = 캡처 일련번호 |
| R 해제 | `rel`마다 이전 단계(I 없으면 `-`)와 단계 6이면 이전 L 유무가 같다. 이어지는 `fr`·`fr_` 쌍마다 (노드, 단계), 호출 전 I·L 유무(I 없으면 L 없음), 호출 뒤 N 해제 또는 I·L 유무가 같고 개수도 같다. 단계 6은 `fr` 0개 |
| D 감쇠 | `dec`마다 현재 노드 I 없음(`noI`)·L 없음(`noL`) 표시가 같고, 둘 다 있으면 조상 열 `as`와 끝 이유 `end`가 같다 |
| K 개수 | 6사례 합계: `nn` 18,021, 해제 요청(0·3·4) 23,939, L 생성(6) 19,325, `dec` 8,972(조상 열 7,404 = `noI` 7,238 + `nop` 166, I·L 없음 1,568), `fr` 40,496 |
| T 변조 | Rust 출력 변조 6종(이전 단계, `fr` 단계, `fr` 줄 삭제, `fr` 뒤 상태, 조상 일련번호, 끝 이유)이 각각 거부된다 |
| V 변이 | `node_life.rs` 작업 복사본에 아래 변이를 넣어 다시 돌린다. 사례별 거부·생존이 표와 같아야 한다(실행 전 고정, 근거는 06f-2 §3 V와 §6 결과) |

| 변이 | 바꾼 절(06f-2 W) | 기대 |
|---|---|---|
| W1 | `old < 5` 멈춤 제거 | 6사례 거부 |
| W2 | 부모 단계 < 3 멈춤 제거 | 6사례 생존(분기 0회) |
| W3 | 자식 수 연쇄 제거 | 6사례 거부 |
| W4 | `s > 4` 멈춤을 `s > 3`으로 | 6사례 거부 |
| W5 | 부모 I 해제를 단계 1 대신 0으로 | 6사례 거부 |
| W6 | 루트 예외 제거 | 6사례 거부 |

- 변이가 죽은 노드를 참조해 panic하면 그 사례만 실패 줄을 쓰고 다음 사례로 간다(사례별 판정 유지).
- 수치 비교: 없음. 정수·참거짓·일련번호의 정확 비교다.
- 시간·work·병렬: Threads=1 캡처(06f-2와 같음). 해당 없음.
- 원본 재현성: 06f-2 L1(6사례×3회 gz 바이트 동일)을 재사용한다. 재캡처하지 않는다.
