# M2-03d-11 검증 계약과 결과: DynamicRows 관문 입력 오라클

작성 기준은 [스프린트 검증 기준](../15_sprint_verification.md)이다. 배경은 [M2-03d-8](mip_dive_rows.md) §6.3과 [M2-03d-10](mip_dive_list_rust.md) §7이다. 03d-8 `d:gate`는 관문 통과로 예측한 판정만 입력을 남겼고 실패는 첫 실패 절별 개수만 셌다. 그래서 03d-10은 관문을 이식하지 못했다. M2 인수인계의 첫 제안 항목이고, 사용자의 "다음 스프린트 진행" 지시로 착수했다(2026-11-11).

## 1. 범위와 주장

- 작업 종류: 오라클 구축. 원본 실행 훅으로 두 관문의 모든 판정(실패 포함)에서 절 입력의 원시 값과 결과를 캡처한다. 그 입력으로 C 규칙을 재구성한 Python 판정을 둔다. Rust 솔버 코드는 바꾸지 않는다.
- 완료 후 주장할 것: 계약 사례에서 C:526 재활성 관문과 C:1581 선택 관문의 판정마다 절 입력 값이 남는다. §2 규칙이 그 값에서 원본 결과(양성 훅으로 따로 관측)를 정확히 재현한다. 각 절이 실행에서 결과를 바꾸는지(판별력)를 절별로 보고한다. 03d-8 §6.3은 두 관문의 노드 조건을 횟수로만 맞췄다. 이번에는 `5fb8ec` 호출별로 대조한다.
- 포함 분기:
  - C:526(`0x510940`): DynamicRows(env+0x2b48)≠0, `I+0x2c`=`W+0x34`이면 `10e662`를 부른다.
  - C:1581(`0x512468`): DynamicRows≠0, `I+0x2c`=`W+0x34`, `I+0x28`=2, `I+0xa0`≠0, `I+8`≠0을 본다. 통과하면 `0x513078` 뒤에 `a7f0ad(lp)`=0, `a7f923(lp)`=0, `*(param_3+0x18)`<2를 본다(`0x513198`–`0x5131bc`).
  - DynamicRows=0 대조군(03d-8과 같은 설정).
- 제외 범위와 후속:
  - 관문 Rust 이식은 다음 하위 번호로 둔다.
  - `a7f0ad`·`a7f923`은 QP·QCP 판정(`re/notes/10_solve_driver.md`)이라 선형 MIP에서는 0으로 예상한다. 반환값은 캡처하지만 0이 아닌 사례(MIQP·MIQCP)는 만들지 않는다. 실행에서 갈리지 않으면 C만으로 보고한다.
  - `W+0x34`는 `6e8eb3`이 노드를 꺼낼 때 그 노드의 `I+0x2c`(깊이)를 쓴다(C:200–202, C:369–373). 이 출처는 C로만 기록하고 실행으로 대조하지 않는다.
  - `param_3+0x18`의 의미, DynamicRows=−1 자동 판정의 내부(env 값을 바꾸는 쪽)는 조사하지 않는다. 실행 중 env 값만 캡처한다.
- 선행: main `2bc84de`. 미커밋 선행 변경 없음.

## 2. 원본과 상태 경계

- Gurobi 13.0.3, SHA-256 `8e87fca221fdffc922331c8619426031b3e72dfd419446422f88af0cb0e98f9c`. 주소는 file offset(= objdump 주소)이다.
- 원본(C 읽기, asm 대조):

| 위치 | 내용 |
|---|---|
| `5fb8ec` 진입 `0x5101d0` | rsi=`param_2`(W)를 rbx에(`5101e1`), rdx=`param_3`을 r15에(`5101e7`) 둔다. rbx는 `5108c4`·`51128f`에서 `0x110(%rsp)`로 다시 읽는다 |
| `0x510940` C:526 | `cmpl $0,0x2b48(%r12)`(9바이트). 들어오는 jmp는 `510939` 하나이고 `51093b`에서 이어진다. I=`*(0x130(%rsp))+0x18`, `cmp 0x34(%rbx)` |
| `0x510961` | `10e662` 호출 준비(8바이트 `mov`). 들어오는 jmp 없음. 여기 도달 = C:526 참 |
| `0x512468` C:1581 | 03d-8과 같다. `511b22`·`511b93`이 직접 점프하므로 I는 `0x130(%rsp)`로 읽는다 |
| `0x51305f` | 앞 세 절 통과 뒤 `je`(`51248e`)로만 온다. `I+0xa0`·`I+8` null 검사 |
| `0x513078` | 다섯 절 통과(03d-8 훅) |
| `0x51319d`·`0x5131af` | `a7f0ad`·`a7f923` 반환 직후 `test %eax,%eax`. 들어오는 jmp 없음 |
| `0x5131b7` | `cmpl $2,0x18(%r15)`. r15는 진입 rdx이지만 경로 중 다시 쓰이므로(`511297` 등) 실행에서 `param_3`과 같은지 확인한다 |
| `0x5131c2` | 세 절 모두 통과. 실패하면 `0x513b12`로 간다 |

- 시작·끝: `5fb8ec` 한 호출 안의 관문 평가 한 번이 사건 하나다. 계측은 메모리 읽기만 한다.
- 입력(관문 명령마다 앞 절이 실패해도 모두 읽는다): dyn, `I+0x2c`, `W+0x34`, `I+0x28`, `I+0xa0`·`I+8`의 null 여부, `*(param_3+0x18)`, 노드 번호(`*node`), MIP 깊이, `5fb8ec` 호출 순번과 그 호출 안의 평가 순번. `0x130(%rsp)` 노드가 진입 `*param_1`과 같은지, rbx가 진입 `param_2`와 같은지도 남긴다.
- 결과(양성 훅): C:526은 `0x510961` 도달. C:1581은 `0x51305f`·`0x513078`·`0x51319d`(eax)·`0x5131af`(eax)·`0x5131b7`(r15+0x18, r15=`param_3` 여부)·`0x5131c2` 도달.
- 비간섭: 새 도구 `tools/mip_dive_gate.js`는 03d-8 `tools/mip_dive_rows.js`를 복사해 훅을 그대로 둔다. 같은 주소(`0x5101d0`·`0x512468`)는 한 리스너 안에서 새 사건만 더한다. `b:*`·`d:*` 사건 투영이 03d-8 캡처와 같아야 한다. 03d-8 도구 파일은 고치지 않는다.
- 설정: 03d-8과 같다(§4).

## 3. 비교 계약

`tools/mip_dive_gate_check.py`가 판정한다. 하나라도 실패하면 종료코드 1이다.

| 검사 | 규칙 |
|---|---|
| M 입력 | 각 회차가 정상 종료했고(03d-8과 같은 `DONE` 줄, 오류 없음) 바이너리·모델·도구 해시와 파라미터가 맞다. manifest 파일 해시가 같다 |
| B 재현 | 사례마다 독립 3회의 사건 전체가 정확히 같다 |
| N 비간섭 | 각 회차의 `b:*`·`d:*` 투영이 같은 사례의 03d-8 캡처(`bench/oracle/mip_dive_rows/*_1.json.gz`) 사건 목록과 같다 |
| I 식별 | 모든 관문 사건에서 rbx=`param_2`, `0x130(%rsp)` 노드=진입 `*param_1`이다. `0x5131b7` 도달 시 r15=`param_3`이고 r15+0x18 값이 관문 시점 값과 같다 |
| R 규칙 | 모든 관문 사건에서 §1 규칙으로 계산한 양성 훅 도달 열이 캡처와 정확히 같다(C:526은 `0x510961`, C:1581은 `0x51305f`→`0x513078`→`0x51319d`→`0x5131af`→`0x5131b7`→`0x5131c2`의 도달 길이) |
| P 짝 | top-level·중첩 MIP 모두 `5fb8ec` 호출마다 C:526 평가는 최대 한 번(앞선 조기 반환이 있을 수 있다)이고, 같은 호출의 C:1581 평가 각각과 노드·dyn·`I+0x2c`·`W+0x34`가 같다(값이 다르면 그 호출을 보고하고 실패). 03d-8 `d:gate`·`d:blocked`·`d:sel` 수와 G 대조가 같다 |
| D 연결 | C:526 참인 top-level 호출 수 = 03d-8 캡처에서 반환 `5fb8ec+0x79e`인 `b:op react_all` 수. `0x5131c2` 도달 수 = `d:sel` 수 |
| C 대조군 | DynamicRows=0 3회: 모든 관문 사건의 dyn=0, 양성 훅 0회 |
| V 판별력 | 규칙 절을 하나씩 바꾼 변종(dyn 무시, 깊이 무시, 상태 2 무시, `I+0xa0`·`I+8` 무시, `a7f0ad`·`a7f923` 무시, `+0x18` 무시·임계 1·3, C:526의 깊이 무시)마다 R이 실패하는지 본다. 실패하지 않은 절은 "실행에서 결과를 바꾸지 않음 → C만"으로 보고하며 판정 실패로 치지 않는다. 절별 참·거짓 횟수를 함께 낸다 |

- 정수·포인터 null 여부·순서는 정확 비교한다. 허용오차는 없다.
- 시간·work: Threads 1, NodeLimit만 쓴다.
- 자기검사(`--self-test`): 바이너리·도구 해시, 파라미터, 회차 차이, 빈 사건, 03d-8 투영, 관문 사건 각 입력 필드(dyn, 깊이, `W+0x34`, 상태, null 여부, `+0x18`), 양성 훅 사건 하나 삭제·추가, 노드 식별 필드, 대조군 양성 훅 추가를 변조해 모두 거부해야 한다. 입력 변조는 결과를 바꾸는 사건을 노린다(통과 사건의 깊이, 실패 사건의 상태 등).
