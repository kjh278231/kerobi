# 13. M1·M2·M3 작업 단위

2026-11-10 기준 작업 목록이다. `M1-01`처럼 마일스톤과 두 자리 번호로 작업을 식별한다. 번호는 식별자이며 실행 순서는 아니다. 기존 G1~G6은 검증 관문으로 유지한다. 이 표의 확인 항목은 각 작업의 산출물을 판정하기 위한 것이며, 마일스톤의 전체 합격 기준을 대신하지 않는다. P0~P3와 마일스톤 관문은 [포팅 가이드](10_porting.md)와 [기존 로드맵](09_roadmap.md)을 따른다.

이 문서의 24개 번호는 상위 작업이다. 실행 단위는 [1주 스프린트 작업 목록](14_sprint_plan.md)의 `M2-05a` 같은 하위 번호다. 작업당 집중 작업 3일과 검증·수정 여유 2일을 계획 예산으로 두고, 착수 때 범위가 넘으면 더 나눈다. 조사 전의 구현 항목은 설계 대기다.

하위 작업의 검증 계약과 완료 판정은 [동작 동등성 검증 기준](15_sprint_verification.md)을 따른다. 기존 완료 이력은 그때 기록한 검증 범위를 유지하며 새 기준의 모든 검사를 소급해 통과했다고 간주하지 않는다.

상태는 **완료(범위 한정)**, **진행**, **예정**으로 표시한다. 완료는 표에 적은 범위의 검증 완료를 뜻한다. 미측정 경로나 다른 설정까지 완료했다는 뜻은 아니다. 진행 기록에는 하위 작업 번호, 변경, 검증 조건과 남은 한계를 적는다. 상세 설계 경계는 [M1](m1/sprint_design.md), [M2](m2/sprint_design.md), [M3](m3/sprint_design.md)에 있다.

## 다음 작업을 고르는 법

현재 진행 중인 MIP 복원과 B&B 후속은 M2-03부터 M2-05에 해당한다. M2-03a·M2-03b-1 조사는 완료했고 M2-03c-1은 부분 완료, M2-03c-2 오라클과 M2-03d-1 비교 경계 조사는 완료다. M2-03d-2 재풀이 판단 제어는 L1 비교로 완료했다(실제 경로 미연결). 노드 LP 원본 캡처(M2-03d-3)도 완료했다. 실제 경로 연결과 LP 포함 동등성은 M2-03d-4다. 원본 두 사례는 일반 B&B 노드가 아니어서 실제 경로 검증에는 별도 사례가 필요하다. M2-03d-5 스캔(228회)에서 재시작 뒤 본 탐색 일반 노드 사례 1건을 찾았고(재시작 없는 노드는 0건), 그 노드 LP 캡처 M2-03d-6도 완료했다(재풀이 primal → 2, simplex ws는 96행을 비운 LP). M2-03d-7에서 그 빈 행이 DynamicRows 다이브 행 비활성(`5fb8ec`→`10e5fc`→`edd71`, `cda5b`의 `10f448` 교체)임을 확인했다. 행 선택 규칙은 M2-03d-8 오라클로 대조했다(Python 재구성이 원본 선택 2,093건과 정확히 일치, Rust 이식은 미착수). 하위 번호의 선행 조건과 산출물은 스프린트 작업 목록에서 확인한다. 새 기능을 시작하기 전에는 해당 작업의 원본 위치, 입력 조건, 검증 방법을 상세 기록에 남긴다.
