# 절차 교훈

형식은 [README](README.md)를 따른다.

- **첫 원본 캡처 전에 계약 골격과 판정 규칙을 커밋한다.** "원본 미생성"도 결론이 될 수 있다는 것, 합성 결과는 참고용이라는 것을 미리 적어 두면, 결과를 본 뒤 범위를 좁히고 싶은 유혹이 사라진다. (M2-03c-2)
- **필드표를 고정하기 전에 탐색 캡처를 1회 한다.** 어떤 훅이 실행되는지만 센다. 이 한 번으로 리스너 결함과 예상하지 못한 export 경로(`5d4427`, `68341b`)가 드러났다. (M2-03c-2)
- **도달할 수 있는지부터 원본 C·asm으로 판정한다.** 정상 산술에서 불가능한 사건(자연 5→12)을 같은 지시로 계속 찾지 말고, 합성 경계로 바꿀지 사용자에게 확인한다. (M2-03c-1)
- **shared 점유는 다른 세션이 오래 갖고 있을 수 있다.** 공유 문서를 갱신하기 직전에 확인한다. 비어 있으면 점유한 뒤, 로컬 작업 branch를 최신 main 위로 rebase하고 갱신한다. 병합 뒤에는 병합된 트리에서 검사기를 다시 돌린다. (M2-03c-2)
- **완료를 선언하기 전에 독립 검토(advisor 또는 다른 모델)를 받는다.** 주소 오타와 C/캡처 근거 혼동은 자체 검사기로는 잡히지 않았다. (M2-03c-2)
- **Rust 대응 작업 전에 원본 사례의 입력을 Rust가 다시 만들 수 있는지 먼저 본다.** 캡처의 LP 행·열 수를 모델 파일과 비교하고 호출 문맥(휴리스틱·sub-MIP)을 확인한다. 만들 수 없으면 원본 결과를 주입한 구간 재생(합성으로 표시)과 LP 포함 재생을 나눠 계약한다. (M2-03d-1, [§3](../m2/mip_retry_rust_boundary.md#질문-2-같은-입력-상태-도달-가능성))
- **원본 LP 결과를 주입하는 구간 재생에서는 판단 코드가 LP를 클로저로 받게 하고, trace는 하네스가 클로저 인자와 반환값으로 만든다.** 판단 코드에 계측·테스트 분기가 들어가지 않고, 같은 함수를 실제 경로에서 다시 쓸 수 있다. 주입값이 그대로 나오는 필드는 판별 필드로 세지 않는다. (M2-03d-2, [§7](../m2/mip_retry_control.md#7-판정과-인수인계))
