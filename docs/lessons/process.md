# 절차 교훈

형식은 [README](README.md)를 따른다.

- **첫 원본 캡처 전에 계약 골격과 판정 규칙을 커밋한다.** "원본 미생성"도 결론이 될 수 있다는 것, 합성 결과는 참고용이라는 것을 미리 적어 두면, 결과를 본 뒤 범위를 좁히고 싶은 유혹이 사라진다. (M2-03c-2)
- **필드표를 고정하기 전에 탐색 캡처를 1회 한다.** 어떤 훅이 실행되는지만 센다. 이 한 번으로 리스너 결함과 예상하지 못한 export 경로(`5d4427`, `68341b`)가 드러났다. (M2-03c-2)
- **도달할 수 있는지부터 원본 C·asm으로 판정한다.** 정상 산술에서 불가능한 사건(자연 5→12)을 같은 지시로 계속 찾지 말고, 합성 경계로 바꿀지 사용자에게 확인한다. (M2-03c-1)
- **shared 점유는 다른 세션이 오래 갖고 있을 수 있다.** 공유 문서를 갱신하기 직전에 확인한다. 비어 있으면 점유한 뒤, 로컬 작업 branch를 최신 main 위로 rebase하고 갱신한다. 병합 뒤에는 병합된 트리에서 검사기를 다시 돌린다. (M2-03c-2)
- **완료를 선언하기 전에 독립 검토(advisor 또는 다른 모델)를 받는다.** 주소 오타와 C/캡처 근거 혼동은 자체 검사기로는 잡히지 않았다. (M2-03c-2)
- **Rust 대응 작업 전에 원본 사례의 입력을 Rust가 다시 만들 수 있는지 먼저 본다.** 캡처의 LP 행·열 수를 모델 파일과 비교하고 호출 문맥(휴리스틱·sub-MIP)을 확인한다. 만들 수 없으면 원본 결과를 주입한 구간 재생(합성으로 표시)과 LP 포함 재생을 나눠 계약한다. (M2-03d-1, [§3](../m2/mip_retry_rust_boundary.md#질문-2-같은-입력-상태-도달-가능성))
- **원본 LP 결과를 주입하는 구간 재생에서는 판단 코드가 LP를 클로저로 받게 하고, trace는 하네스가 클로저 인자와 반환값으로 만든다.** 판단 코드에 계측·테스트 분기가 들어가지 않고, 같은 함수를 실제 경로에서 다시 쓸 수 있다. 주입값이 그대로 나오는 필드는 판별 필드로 세지 않는다. (M2-03d-2, [§7](../m2/mip_retry_control.md#7-판정과-인수인계))
- **구현 경계를 고르기 전에 그 구간이 읽는 값이 캡처에 모두 있는지 asm으로 확인한다.** 인계는 "pivot 또는 flip 한 건"이었지만 판정이 읽는 `0x1ec8(%rsp)`와 이탈 상태의 `local_250`이 캡처에 없었다. 같은 원본 함수를 자연·합성 모두 관측한 ratio로 좁혔고, 빠진 입력은 오라클 확장 번호로 넘겼다. (M3-04c)
- **Rust 판별력은 분기별 소스 변조를 실제 원본 대조에 돌려 확인하고, 살아남은 변조를 미검증 경계로 적는다.** 사례가 많아도 Harris 여유 때문에 상한 동률이 생기지 않는 등 일부 경계는 저장 사례로 가를 수 없었다. 변조 도구는 원본 소스를 `finally`에서 되돌린다. (M3-04c, `tools/primal_push_ratio_rust.py --mutate-rust`, M3-04c-6)
  오라클에 모델 변조 목록이 있으면 같은 목록을 Rust 소스 변조로 옮긴다. 거부·생존 분류가 오라클과 같아야 하고, 오라클이 거부한 변조를 Rust 하네스가 놓치면 하네스가 약한 것이다. M3-04c-6에서는 20종 중 19종을 옮겼고 분류가 같았다. ([§6](../m3/primal_push_decision_rust.md#6-실행-결과))
- **블록 대각 묶음을 하나의 LP로 합치면 crash basis가 단독 실행과 달라질 수 있다.** 단독으로는 push되던 구조 열이 결합 LP에서 basic이 되고 그 행 slack이 대신 진입했다. 묶음 단독 탐색으로 설계하고, 판정은 고정한 결합 LP 캡처의 단계별 변수 대응으로 다시 확인한다. (M3-04b-3, [§6](../m3/primal_push_arms_oracle.md#6-실행-결과))
- **사건 부재로 추정하던 분기(보류)는 양성 훅을 붙여 확인하고, 사건이 없으면 실패로 판정한다.** 부재 추정은 다른 종료 경로와 구별하지 못한다. (M3-04b-3)
- **모든 종단을 "밟는" 사례와 각 절을 "판별하는" 사례는 다르다.** 첫 설계(p3)는 위반 방향식 10종단을 모두 관측했지만 절을 하나 끄면 다음 절이 같은 방향을 내 변조가 살아남았다. 대상 캡처 전에 탐색 캡처로 모델 변조를 돌려 생존 절마다 "꺼지면 반대 방향"이 되는 묶음을 더했다. (M3-04c-2, [§4.2](../m3/primal_push_violated.md#42-탐색합격-근거-아님))
